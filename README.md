# Vite React TypeScript App

This is a Vite React application built with TypeScript. It includes the following libraries:
- **reactstrap**: For UI components and styling.
- **React-redux**: For state management.
- **axios**: For handling HTTP requests with interceptors for authentication.

## Prerequisites

Make sure you have the following versions installed:
- **react**: ^17.0.0
- **react-dom**: ^17.0.0
- **react-router-dom**: ^5.2.0

## Running the Server
Before starting the development server, ensure that the backend server is running. By default, it runs on port 9000. You can customize the port in the `.env` file as needed.

## Setup

To get started with the project, follow these steps:

1. **Install dependencies:**
  ```bash
  npm install
  ```

2. **Start the development server:**
  ```bash
  npm run start
  ```
